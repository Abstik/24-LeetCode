## [977. 有序数组的平方](https://leetcode.cn/problems/squares-of-a-sorted-array/)

![image-20250524200242112](https://gggzxh.oss-cn-beijing.aliyuncs.com/img/20250524200242112.png) 

```go
func sortedSquares(nums []int) (num []int) { 
    num=make([]int,len(nums)) 
    for i:=0;i<len(nums);i++ {
        x :=nums[i]
        num[i]=x*x
    }
    sort.Ints(num)
    return 
}
```
