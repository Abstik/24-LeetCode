## [654. 最大二叉树](https://leetcode.cn/problems/maximum-binary-tree/description/)

![image-20250525182653997](https://ting2.oss-cn-beijing.aliyuncs.com/picture/202505251826137.png)

```go
//左区间构造左子树，右区间构造右子树

func constructMaximumBinaryTree(nums []int) *TreeNode {
    len := len(nums)
    if len == 0{   //没有左区间或者右区间了
        return nil
    }

    max := 0   //记录最大值的下标
    for i,v := range nums{
        if v > nums[max]{
            max = i
        }
    }

    return &TreeNode{
        nums[max],
        constructMaximumBinaryTree(nums[:max]),      //左区间构造左子树   
        constructMaximumBinaryTree(nums[max+1:]),    //右区间构造右子树
    }
}
```

## [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

![image-20250525192516610](https://ting2.oss-cn-beijing.aliyuncs.com/picture/202505251925928.png)

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    if root == nil || root == p || root == q{
        return root
    }

    left := lowestCommonAncestor(root.Left, p, q)   //左子树是否有p或q
    right := lowestCommonAncestor(root.Right, p, q) //右子树是否有p或q


    //左为空，右不空，返回右；左不空，右为空，返回左
    //左右都空，返回nil
    if left == nil{
        return nil
    }
    if right == nil{
        return left
    }

     //左右都不为空，返回root
    return root
}
```
