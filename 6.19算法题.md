## [105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

![image-20250524200228265](https://gggzxh.oss-cn-beijing.aliyuncs.com/img/20250524200228265.png) 

```go
//整体思路与上一题相同
func buildTree(preorder []int, inorder []int) *TreeNode {
    n:=len(preorder)
    if n==0 {
        return nil
    }
    leftSize :=slices.Index(inorder,preorder[0])
    left:=buildTree(preorder[1:leftSize+1],inorder[:leftSize])//这里要注意前序遍历数组中索引为0的表示根节点，所以索引1到leftSize表示左子树因此在写切片时要加一，下同
    Right:=buildTree(preorder[leftSize+1:],inorder[leftSize+1:])
    return &TreeNode{preorder[0],left,Right}
}
```
